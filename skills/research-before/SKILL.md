**调研或探索任务不是盲目的搜索或检索，收集不可信的或与任务无关的信息会消耗更多的精力**

**在调研或探索任务开始前需要确立好调研或探索的目标。**

# Skill: Research（结构化调研协议）

## 设计调研树模型:

结构化调研的设计阶段是一棵**设计树**:

- **每一层**代表一个调研的层次，由若干待调研**模块**组成
- **每个模块**是下一层的根节点，向下展开为更细粒度的子模块
- **每一层**可表达为一条由模块间调用关系构成的 **pipeline**（A → B → C → ...）
- **非叶子层**：调研清该层的 pipeline——哪些模块存在、各自职责、相互依赖关系
- **叶子层**：将每个模块的调研落实到三个维度：
    1. 调研结果的关键引用（文件位置、文档连接、互联网连接）
    2. 调研结构是否可信, 对置信度的评分(0 ~ 10)
    3. 调研的关键结论

**调研的任务**：逐层遍历设计树，在每一层循环调研，直到该层达标后再下钻，直至整棵树的叶子层全部落实。

## 每层调研流程

```
for each layer (top-down):
    while 当前层未达标:
            1. 识别该层的模块组成和 pipeline（依赖关系）
            2. 批量列出当前层所有待调研的问题
            3. 等待subagent的调研结果
            4. 对调研结果进行合理评估
            5. 调研结果不足以支撑下一个调研节点的开始, 即当层未达标, 继续进入循环
            6. 进入循环前, 应把调研结果和新的疑问作为下一轮的调研输入
         descend: 以本层每个模块为根节点，展开下一层
```

> 在调研前声明: 我会使用结构化调研协议开展调研工作, 在设计调研方案前我会一步步的思考。


## 输出格式
> 我已明确调研的目标是 ______ 。
> 经过 ______ 的思考, 我会设计了如下的调研树模型, 这样的设计有助于 ________。

```markdown
            |
layer_1:    | 模块2 ---> 模块3 ----> 模块4

            |
layer_n:    | 模块n ----> 模块n+1
```
